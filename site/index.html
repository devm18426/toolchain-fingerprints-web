Each row is one target ABI: architecture, endianness, word size, C library, loader and float ABI. Open a row for the toolchains that build for it, oldest gcc first, with what changed from the row above tinted. Verdicts are OK, RISKY or NO, with the reasons, best first. Toolchains whose compiler ran but compiled nothing are marked compile failed and never matched. No-MMU toolchains produce bFLT (uClinux flat) binaries: they run only on bFLT targets, and ELF toolchains only on ELF ones. copy pull copies the docker pull command for the exact image a toolchain was measured from.

Dataset: fingerprints.json, schema ?. Each record is computed once from a pinned toolchain Dockerfile.
